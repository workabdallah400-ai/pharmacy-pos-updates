# Pharmacy POS — Cloudflare Worker (رابط دائم للتقارير)

سيرفر التقارير يعمل على **Cloudflare Workers** بدل السيرفر المحلي:

| | |
|---|---|
| **الرابط** | `https://pharmacy-reports.<اسمك>.workers.dev` — **دائم** لا يتغير |
| **التخزين** | Cloudflare KV (الخطة المجانية) — البيانات محفوظة للأبد |
| **النوم** | لا ينام أبداً — كود QR يفتح التقرير في أي وقت |
| **المزامنة** | الكمبيوتر يرفع صورة كاملة بعد كل تقفيل وردية + كل 15 دقيقة |

نفس محرك التقارير المستخدم في السيرفر المحلي (`server/report-core.cjs`) — يعني
نفس الشكل العربي بالظبط.

---

## Setup (مرة واحدة)

```powershell
# من مجلد المشروع
powershell -ExecutionPolicy Bypass -File scripts/setup-worker.ps1
```

السكربت يعمل 3 خطوات:

1. **تسجيل الدخول** — يفتح المتصفح، سجّل دخولك إلى Cloudflare (حساب مجاني كافي)
   ووافق على الطلب.
2. **إنشاء KV** — ينشئ مساحة التخزين الدائمة ويحفظ معرّفها في `wrangler.toml`.
3. **النشر** — ينشر الـ Worker ويطبع الرابط الدائم.

### أو يدوياً

```powershell
cd worker
npm install
npx wrangler login
npx wrangler kv namespace create REPORTS     # copy the id into wrangler.toml
npx wrangler deploy
```

---

## بعد النشر

1. **الإعدادات ← المزامنة السحابية ← رابط سيرفر التقارير**
   اكتب الرابط الدائم واضغط **«اختبار الاتصال»** → لازم يطلع ✅.
2. لو عايز حماية للبيانات: في `worker` نفّذ
   `npx wrangler secret put REPORT_TOKEN` واكتب نفس الرمز في
   **رمز حماية التقارير** داخل البرنامج (بيتشتغل تلقائياً مع الـ QR).
3. اقفل «استخدم هذا الرابط العام في كود QR» (النفق السريع) — رابط الـ Worker
   أفضل وأدائم.

## المسارات (نفس السيرفر المحلي)

| المسار | الوصف |
|---|---|
| `GET /` | فهرس كل التقارير |
| `GET /r/<shiftId>` | **تقرير الوردية — ده هدف كود QR** |
| `GET /d/YYYY-MM-DD` | **ملخص اليوم — الرابط اللي المالك بيحفظه** |
| `GET /m/YYYY-MM` | ملخص الشهر |
| `GET /health` | حالة السيرفر |
| `GET /api/shift/<id>` | بيانات الوردية JSON |
| `GET /api/day/<date>` | بيانات اليوم JSON |
| `GET /api/month/<month>` | بيانات الشهر JSON |
| `POST /api/pharmacy/claim` | حجز معرّف الصيدلية + رمزها الخاص (أول تشغيل) |
| `POST /api/pharmacy/snapshot` | رفع صورة كاملة من البرنامج |
| `POST /api/pharmacy/sync` | رفع طابور العمليات Offline |

## حالة «لم تُرفع بعد» (v1.0.3)

لو الصفحة اتفتحت والبيانات لسه ما وصلتش (الصيدلية أوفلاين):

- كارت «⏳ لم تُرفع البيانات بعد» + سطر **آخر مزامنة** (وقت آخر رفع وصل).
- الصفحة بتعمل تحديث تلقائي (`<meta http-equiv="refresh">`): **30 ثانية** لو
  البيانات لسه ما وصلتش، **45 ثانية** لملخص اليوم، **60 ثانية** للملخص الشهري
  والفهرس → أول ما الصيدلية ترفع، الأرقام بتظهر لوحدها من غير refresh بإيد المستخدم.

## بعد أي تعديل على محرك التقارير

المحرك مشترك بين السيرفر المحلي والـ Worker، فلازم تنسخه قبل النشر:

```powershell
node scripts/sync-worker-core.cjs    # من جذر المشروع
cd worker && npx wrangler deploy
```

npm run test:worker
