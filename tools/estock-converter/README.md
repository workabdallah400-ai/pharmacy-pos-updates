# محوّل نسخ eStock الاحتياطية → PharmacyPOS

أداة تُحوّل أي نسخة احتياطية من برنامج **eStock** (ملف `.bak` الخاص بـ SQL Server)
إلى **ملف استيراد واحد** يدخل مباشرة إلى PharmacyPOS.

---

## المتطلبات (مرة واحدة على جهاز التحويل)

1. **Windows 10/11**
2. **SQL Server 2022 Express** مثبّت باسم المثيل الافتراضي `SQLEXPRESS`
   - الأداة تستخدم SQL Server **مؤقتاً** فقط لفكّ ضغط ملف `.bak` ثم تحذف قاعدة البيانات بعد الانتهاء.
   - إن لم يكن مثبّتاً: نزّل `SQLEXPRESS_x64_ENU.exe` من موقع مايكروسوفت وثبّته بالإعدادات الافتراضية.
3. مساحة حرة ≈ **3 أضعاف حجم ملف النسخة** (ملف 250MB يحتاج ≈ 750MB مؤقتة).

---

## طريقة الاستخدام

1. انسخ مجلد `tools\estock-converter` إلى جهازك.
2. انقر نقراً مزدوجاً على **`convert.bat`** ثم اسمح لطلب الـ UAC.
3. اختر ملف النسخة الاحتياطية `.bak` من نافذة الملفات.
4. انتظر انتهاء التحويل (دقيقة إلى 5 دقائق حسب حجم الملف).
5. ستجد مجلداً جديداً بجانب ملف `.bak` باسم:

```
eStock-Export-YYYY-MM-DD\
   eStock-Import.json     ← الملف الذي تستورده في البرنامج
   convert-log.txt        ← سجل العملية (للمراجعة عند أي مشكلة)
```

6. افتح **PharmacyPOS → الإعدادات العامة → النسخ الاحتياطي والأمان →
   «استيراد كتالوج من برنامج آخر (eStock)»**، اختر `eStock-Import.json`،
   راجع الأعداد المعروضة ثم اضغط **تأكيد الاستيراد**.

> الاستيراد يضيف الأصناف والموردين غير الموجودين عندك، **ويحدّث أسعار وتعبئة
> وباركود** الأصناف المتشابهة (المطابقة بالباركود أولاً ثم بالاسم).
> لا يضيف أرصدة ولا دفعات مخزون — الكتالوج فقط.

---

## ماذا يُستخرج؟

| البيانات | التفصيل |
|---|---|
| الأصناف | الاسم العربي/الإنجليزي، الاسم العلمي، التصنيف، نوع الوحدة |
| الباركود | الباركود الداخلي من eStock (يُترك فارغاً إن لم يوجد) |
| الأسعار | سعر العلبة، سعر الشريط، سعر الوحدة (القرص/الزجاجة…) |
| التعبئة | عدد الشرائط في العلبة، عدد الوحدات في الشريط |
| المخزون | يُقرأ من المصدر للعلم فقط — البرنامج **لا يستورد أرصدة ولا دفعات**؛ الكتالوج يبقى بدون رصيد |
| الموردون | الاسم، الهاتف، العنوان، الرصيد |
| العملاء | الاسم، الهاتف، العنوان، سقف الائتمان، الرصيد (تُصدَّر لكن لا تُستورد تلقائياً) |

---

## أسئلة متكررة

**هل تُعدَّل بيانات eStock الأصلية؟**
لا. يُنسخ ملف `.bak` إلى مجلد عمل مؤقت، وتُحذف قاعدة البيانات المؤقتة بعد التحويل.

**هل أحتاج SQL Server على جهاز الصيدلية؟**
لا. SQL Server مطلوب **فقط** على جهاز التحويل.

**ظهر خطأ «تعذّر الاتصال بـ SQL Server»**
شغّل الأداة كمسؤول (Run as administrator). إن استمر، تأكد أن خدمة
`SQL Server (SQLEXPRESS)` تعمل من `services.msc`.

**الملف كبير والتحويل بطيء**
طبيعي؛ بناء ملف JSON لـ 50 ألف صنف يستغرق دقيقتين تقريباً.

**أريد استيراد بيانات صيدلية أخرى**
كرر الخطوات مع ملف `.bak` الخاص بها. الأصناف الموجودة مسبقاً تُحدَّث أسعارها وتعبئتها تلقائياً.
