الإصدار الآمن — توقيع Ed25519

🔐 أداة تراخيص صيدليتي

تم إلغاء أداة الويب القديمة نهائياً لأنها كانت تعتمد على «سرّ رئيسي» مكتوب داخل البرنامج، ما سمح لأي شخص بتوليد مفاتيح تفعيل. النظام الجديد يوقّع كل مفتاح بمفتاح خاص يبقى على جهاز المطور فقط، والبرنامج على جهاز العميل يتحقق منه بالمفتاح العام.

⚠️ لا تشارك المفتاح الخاص

المفتاح الخاص يُخزَّن داخل مجلد private/ المستثنى من Git. الملف الوحيد الذي يُوزَّع مع البرنامج هو المفتاح العام في src/utils/licensePublicKey.js. لا ترفع مجلد private/ إلى أي مستودع أو نسخة احتياطية سحابية عامة.

١) توليد زوج المفاتيح (مرة واحدة فقط)

npm run license:keygen

ينشئ مفتاحاً عاماً داخل التطبيق ومفتاحاً خاصاً في private/license-private-key.jwk.json. للتخزين المشفّر: 

npm run license:keygen -- --encrypt

٢) إصدار ترخيص لجهاز عميل

كود الجهاز يظهر على شاشة التفعيل بصيغة EGYP-XXXX-YYYY-ZZZZ.

npm run license:issue -- EGYP-9B4C-D478-B27C

ترخيص لمدة سنة:

npm run license:issue -- EGYP-9B4C-D478-B27C --type=TIMED --days=365

أو حتى تاريخ محدد:

npm run license:issue -- EGYP-9B4C-D478-B27C --type=TIMED --until=2027-12-31

أرسل للعميل الرمز الناتج كاملاً (يبدأ بـ LIC2. وهو حساس لحالة الأحرف).

٣) إلغاء ترخيص جهاز

npm run license:revoke -- EGYP-9B4C-D478-B27C --reason="عدم سداد"

أدخل رمز الإلغاء في شاشة التفعيل على جهاز العميل. بعدها لا يعمل أي ترخيص صادر قبل لحظة الإلغاء، ولا يمكن إعادة التفعيل إلا برمز جديد صادر بعدها.

ولإيقاف جهاز حتى لو لم يُدخل العميل رمز الإلغاء: 

npm run license:revocations

يحدّث قائمة الإلغاء المدمجة داخل البرنامج. بعد بناء إصدار جديد (npm run dist) ونشره، يُرفض الجهاز الملغى في كل نسخة جديدة حتى بدون إنترنت. القائمة تُبنى تلقائياً في كل عملية dist.

٤) لوحة الإدارة الرسومية

npm run license:admin

تفتح لوحة محلية على http://127.0.0.1:4310/ (هذا الجهاز فقط، ولا تُفتح على الشبكة) فيها: إصدار ترخيص دائم أو مؤقت، إلغاء فوري مع رمز REVOKE، إدارة قائمة الإلغاء، وسجل كل ما صدر. المفتاح الخاص يبقى داخل العملية ولا يصل للمتصفح.

٥) فحص رمز قبل إرساله

npm run license:inspect -- LIC2.xxxxxxxx.yyyyyyyy

٦) تشغيل الاختبارات

npm run license:test

تتحقق من التوقيع، ورفض الرموز المعدّلة والأجهزة الأخرى والمنتهية، ورفض الأكواد القديمة، ونافذة الإلغاء.

ملاحظات أمنية

  • البرنامج لا يحتوي على أي سرّ يمكن استخدامه لتوليد تراخيص.
  • أي مفتاح قديم بصيغة LIC-LIFE-* أو LIC-EXP-* أو REVOKE-* مرفوض.
  • الترخيص مرتبط بكود الجهاز؛ نسخه لجهاز آخر لا يعمل.
  • ساعة الجهاز محمية ضد الرجوع للخلف، وتراخيص المدة المحددة تنتهي بتاريخها الموقّع.
