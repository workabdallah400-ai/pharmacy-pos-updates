# PharmacyPOS License Studio

أداة سطح مكتب مستقلة (Electron) لإدارة تراخيص PharmacyPOS على جهاز المطور فقط.

## التشغيل

```bash
cd license-studio
npm install
npm run start   # تشغيل مباشر
npm run dist    # إنتاج portable exe داخل license-studio/release
```

## أول تشغيل

1. اضغط **استيراد ملف المفتاح…** واختر `private/license-private-key.jwk.json` من مجلد المشروع.
2. يُحفظ المفتاح مشفّراً بمفتاح ويندوز (DPAPI) داخل `userData` ولن يُطلب مرة أخرى.
3. تأكد أن الشريحة أعلى اليمين تقول **«المفتاح جاهز»**؛ لو ظهر «لا يطابق التطبيق» فلا تستخدمه.

## الاستخدام

| التبويب | الوظيفة |
|---|---|
| ① إصدار ترخيص | كود جهاز العميل → دائم أو مؤقت (أيام/تاريخ) → نسخ رمز `LIC2.…` |
| ② إلغاء ترخيص | كود الجهاز + السبب → رمز `REVOKE` يوقفه فوراً |
| ③ الأجهزة الملغاة | مراجعة/إزالة الأجهزة من قائمة الإلغاء المحلية |
| ④ سجل التراخيص | كل ما أصدرته مع التواريخ |
| ⑤ تصدير قائمة الإلغاء | كتابة `src/utils/licenseRevocations.js` ثم `npm run dist` ونشر الإصدار |
| ⚙️ المفتاح | حالة المفتاح، البصمة، الاستبدال أو الحذف |

## ملاحظات أمنية

- المفتاح الخاص لا يُبنى داخل التطبيق ولا يُرسل لأي شبكة؛ كل شيء محلي.
- الأداة تُصدر نفس صيغة `LIC2` التي يتحقق منها البرنامج (Ed25519 + kid `2026-11`).
- لا تستخدم `npm run license:keygen` إلا لو كنت تريد إبطال كل الأكواد الصادرة.
- ملفات الأداة نفسها (`main.cjs`, `core.cjs`, `preload.cjs`) لا تحتوي أي مفتاح خاص.
